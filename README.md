## 🛠️ How to Compile & Run

### Using g++ (Recommended)

```bash
g++ filename.cpp -o output
./output
```

### Using Visual Studio

1. Open `.cpp` file in Visual Studio
2. Press `Ctrl + F5` to compile and run
